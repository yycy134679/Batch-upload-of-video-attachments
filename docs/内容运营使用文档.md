# 飞书表格视频附件批量上传工具使用文档

这份文档只保留运营同事最常用的信息，目标是帮助你快速、安全地完成一次批量上传。

## 这个工具做什么

- 把一个文件夹里的视频，按文件名顺序上传到飞书表格指定列
- 从你填写的起始行开始，逐行写入附件
- 登录一次飞书后，后续可以直接复用登录状态
- 每次运行都会生成报告，失败时会保存截图

## 开始前先确认

开始上传前，只需要确认这 4 件事：

1. 你已经拿到并打开过 `飞书附件批量上传.app`
2. 电脑可以联网
3. 你知道本次要上传的飞书表格地址、目标列、起始行
4. 你已经把本次要上传的视频放进一个单独文件夹

建议：

- 文件夹里不要混入旧文件、测试文件或无关文件
- 上传前先自己打开一次表格，确认列和起始行没有填错

## 第一次使用

### 1. 打开应用

双击打开 `飞书附件批量上传.app`。

首次启动时，应用可能会自动初始化浏览器内核，需要联网并等待几分钟。初始化完成后，界面才可以继续登录和上传。

### 2. 登录飞书

如果界面提示需要登录：

1. 点击 `登录飞书`
2. 在打开的浏览器窗口里扫码登录
3. 等待应用提示登录成功

如果要切换飞书账号：

1. 点击 `清理登录信息（切换账号）`
2. 确认清理
3. 重新点击 `登录飞书`

## 标准上传步骤

### 1. 填写表格地址

把目标飞书表格 URL 粘贴到 `表格地址`。

### 2. 选择视频目录

可以点击 `选择目录`，也可以直接把文件夹拖进窗口。

### 3. 设置上传位置

- `列`：例如 `E`
- `起始行`：例如 `23`

如果你填的是 `E` 和 `23`，那么文件会依次上传到 `E23`、`E24`、`E25`。

### 4. 选择是否覆盖

- 默认不覆盖：如果目标单元格已有内容，会自动跳过
- 勾选 `允许覆盖已有附件`：会尝试替换已有内容

不确定是否要替换旧附件时，请不要勾选。

### 5. 选择运行模式

- `前台运行（显示浏览器）`：适合第一次使用、观察过程、排查问题
- `后台运行（无头）`：适合安静地批量执行

注意：`登录飞书` 时始终会打开可见浏览器窗口。

### 6. 开始上传

点击 `开始上传` 后，应用会自动：

1. 检查参数
2. 生成上传计划
3. 打开飞书表格
4. 从起始行开始逐个上传

## 上传过程中你会看到什么

界面里会显示：

- 当前处理到第几个文件
- 每个文件对应的单元格
- 当前状态和说明
- 运行日志

常见状态：

- `上传成功`
- `覆盖成功`
- `跳过已有内容`
- `上传失败`
- `文件缺失`
- `已终止`

## 如果中途不想继续

点击 `终止上传` 即可。

终止后的行为是：

- 不再开始后续文件
- 当前这次文件处理结束后再停下
- 不会关闭应用
- 未开始的文件会标记为 `已终止`
- 已完成的日志和报告会保留

注意：`终止上传` 只作用于上传任务，不作用于初始化和登录流程。

## 上传完成后怎么看结果

重点看 3 个地方：

### 1. 顶部摘要

会显示本次上传成功、跳过、失败等汇总结果。

### 2. 进度表格

可以看到每个文件对应的单元格、状态和说明。

### 3. 报告目录

点击 `打开报告目录`，会打开本次运行的报告文件夹。

里面通常有：

- `summary.json`
- 失败截图（如果有）

如果需要找技术同事协助，优先把这整个报告文件夹发过去。

## 最容易出错的地方

只要记住下面几条，基本就够用了：

- 文件上传顺序只看文件名，不看创建时间
- 起始行一旦填错，后面所有文件都会整体错位
- 文件夹里多一个视频，就会多上传一行
- 前台运行时，不要手动点浏览器页面
- 如果只是想停下来，请点 `终止上传`，不要直接关应用

## 简单排查方法

如果上传失败，按这个顺序看：

1. 看界面日志
2. 看顶部摘要和进度表格
3. 打开报告目录
4. 查看 `summary.json`
5. 查看失败截图

如果还是判断不了，把表格地址、目标列、起始行、是否勾选覆盖、运行模式，以及报告目录一起发给技术同事。
